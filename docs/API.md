# API

Базов адрес: `http://127.0.0.1:8000/api/`. Формат: JSON. Автентикация: JWT токен в заглавката `Authorization: Bearer <access>`.

| Метод | Адрес | Достъп | Описание |
|---|---|---|---|
| POST | `/auth/register/` | всички | Регистрация (потребителско име, имейл, парола) |
| POST | `/auth/login/` | всички | Вход; връща `access` и `refresh` токени |
| POST | `/auth/refresh/` | всички | Нов `access` токен с `refresh` |
| GET | `/routes/` | всички | Списък с маршрути |
| POST | `/routes/` | влезли | Нов маршрут с точки |
| GET | `/routes/<id>/` | всички | Детайли: точки, снимки, средна оценка |
| PUT, PATCH | `/routes/<id>/` | само авторът | Редакция (изпратените точки заместват старите) |
| DELETE | `/routes/<id>/` | само авторът | Изтриване |
| GET | `/routes/<id>/reviews/` | всички | Отзиви към маршрута |
| POST | `/routes/<id>/reviews/` | влезли | Нов отзив с оценка 1 до 5 |
| POST | `/routes/<id>/photos/` | само авторът | Качване на снимка (multipart, поле `image`) |
| DELETE | `/routes/<id>/photos/<photo_id>/` | само авторът | Изтриване на снимка |
| GET | `/users/<username>/` | всички | Публичен профил (без имейл) |

## Филтри на `GET /routes/`
- `?search=текст`: в заглавието, дестинацията и описанието (без значение на главни и малки букви)
- `?author=потребител`: маршрутите на потребител
- `?min_rating=4`: минимална средна оценка
- `?ordering=rating`: първо най-високо оценените

## Примерен маршрут
```json
{
  "id": 1,
  "title": "Седемте рилски езера",
  "destination": "Рила",
  "description": "...",
  "tips": "...",
  "author": "demo_ivan",
  "created_at": "2026-11-02T10:15:00+02:00",
  "waypoints": [
    {"id": 1, "name": "Паничище", "latitude": 42.2686, "longitude": 23.317, "order_index": 0}
  ],
  "photos": [{"id": 1, "image": "http://127.0.0.1:8000/media/route_photos/x.jpg"}],
  "average_rating": 4.7,
  "reviews_count": 3
}
```

## Ограничения при качване на снимки
JPEG, PNG или WebP, до 5 MB, най-много 10 на маршрут. Файлът се проверява реално (отваря се като изображение), а не по разширението.
