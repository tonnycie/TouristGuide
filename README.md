# Туристически пътеводител

Платформа за туристическа общност, в която любителите на пътешествията публикуват, преглеждат и оценяват маршрути.

## Функционалности
- Регистрация и вход (личен акаунт за всеки потребител)
- Публикуване на маршрут: дестинация, междинни точки (избират се с клик върху карта), лични впечатления, съвети за пътуване и снимки
- Преглед на маршрутите върху карта (OpenStreetMap) със снимки
- Текстови отзиви и оценки от 1 до 5, средна оценка на маршрута
- Търсене, филтър по минимална оценка и подредба по оценка
- Профилна страница на потребител
- Редакция и изтриване на собствени маршрути

## Технологии
- **Бекенд:** Python, Django, Django REST Framework, JWT (SimpleJWT), SQLite
- **Фронтенд:** React (Vite), React Router, Axios, Leaflet

## Структура
```
backend/   Django проект (config/) и приложение routes/ (модели, API, тестове)
frontend/  React приложение (src/pages, src/components, src/api)
docs/      ER диаграма, документация на API-то, сценарий за демонстрация
```

## Изисквания
- Python 3.10 или по-нов
- Node.js (LTS)
- Интернет връзка (картата зарежда плочките си от OpenStreetMap)

## Стартиране (Windows, PowerShell)

### Бекенд
```powershell
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```
Бекендът работи на `http://127.0.0.1:8000`, админ панелът е на `/admin/`.

### Фронтенд (втори терминал)
```powershell
cd frontend
npm install
npm run dev
```
Приложението е на `http://localhost:5173`.

### Demo данни
Командата `python manage.py seed_demo` създава 4 потребителя (`demo_ivan`, `demo_maria`, `demo_petar`, `demo_elena`), 5 маршрута и 11 отзива. Парола на всички: `Demo!Pass2026`. С `--reset` данните се създават наново.

## Сигурност
- **Защита от XSS** на два слоя: бекендът маха всички HTML тагове от потребителски текст (заглавия, описания, отзиви, имена на точки), а React екранира всичко при показване (не се ползва `dangerouslySetInnerHTML`).
- Паролите се пазят хеширани, потребителите се автентикират с JWT токени.
- Права: само авторът може да променя и трие своя маршрут и снимките му.
- Качените файлове се проверяват (тип, размер, реално отваряне като изображение).
- Фиксирани граници на координатите (ширина от -90 до 90, дължина от -180 до 180).

## Географски координати
Всяка междинна точка се записва като `latitude` и `longitude` (десетични числа с 6 знака след запетаята), заедно с реда си в маршрута.

## Известни ограничения
Проектът е за локално стартиране: `DEBUG` е включен, базата е SQLite, а JWT токените се пазят в `localStorage`. За публично хостване биха били нужни промени в настройките (таен ключ, `ALLOWED_HOSTS`, HTTPS, друга база).
